설치 / 01

한 줄로 추가합니다.

dart pub add korean_profanity

실제 검사 / 02

입력과 증거를 함께 봅니다.

페이지의 검사는 패키지에 포함된 실제 KoreanProfanityFilter strict 사전을 호출합니다.

입력은 이 페이지 안에서만 처리됩니다. 프리셋은 입력만 바꾸며, 결과는 검사 버튼을 눌렀을 때 갱신됩니다.

API / 03

세 동작, 같은 필터.

불리언 확인부터 원문 범위와 마스킹까지 하나의 불변 필터 인스턴스에서 동기식으로 실행합니다.

contains(text)

포함 여부

허용된 일치가 하나라도 있는지 bool로 반환합니다.

findAll(text)

모든 일치

겹치는 결과를 유지하고, 원문 순서의 불변 목록과 UTF-16 범위를 반환합니다.

mask(text)

원문 마스킹

겹치거나 맞닿은 범위를 합친 뒤 각 원문 스칼라를 한 개의 마스크 문자로 바꿉니다.

경계 / 04

무엇을 잇고, 어디서 멈추는지.

정규화는 의도적으로 좁습니다. 내부 공백과 숫자는 제한적으로 잇지만, 이모지는 경계로 남깁니다.

로컬 실행 / 05

문장은 패키지 밖으로 나가지 않습니다.

검출과 마스킹은 오프라인, 동기식으로 실행됩니다. 이 패키지 자체는 입력을 전송하지 않습니다. 다만 앱의 로깅이나 네트워크 코드는 별도이므로 직접 점검해야 합니다.

빠른 시작 / 06

검출하고, 확인하고, 가립니다.

기본 import에는 오탐을 줄이기 위한 strict 사전이 포함됩니다.

책임 있는 사용 / 07

필터는 판단 보조 수단입니다.

이 패키지는 사전 기반 매처이며 완전한 안전 장치나 중재 정책이 아닙니다. 새로운 표기를 놓치거나 무해한 문장을 표시할 수 있습니다. 서비스 대상에 맞춰 결과를 검토하고, 사람에게 영향을 주는 결정에는 이의 제기 경로를 제공하세요.
